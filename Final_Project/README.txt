For this project, we built an emotional support chatbot, intended to be used by college students
experiencing mental stress. We used a mixture of pre-set FAQs, and elements of CBT (cognitive behavioral
therapy) to help ground responses. 

The index file contains the embeddings and the files containing responses for the FAQs, and JSON objects 
containing more information about each cognitive distortions. Our test folder contains (limited) tests and
describes changes in the prompt (see paper for more elaborate test sets).

To start the demo, simply run the chat.py file!
